## 为什么做 ZenTex

用 LaTeX 写论文，意味着生活在两个视图之间：一边是纯源码，一边是编译出的 PDF。改一句话，要找两遍。有些编辑器能折叠导言区、把 `\section` 画成标题，但它的预览依然是**另一份渲染结果** —— 你是「看」它，而不是「在上面写」。

ZenTex 从一个问题出发：**如果渲染出来的视图*就是*源码本身呢？**

它保留经典的双栏工作流，并加上一层**装饰同一份文本**的「预览」层：章节变成真正的标题，公式用 KaTeX 就地渲染，图片和表格直接内联显示，`\label` / `\cite` / `\ref` 折成小小的 chip。把光标移进任何一块装饰区域，它就变回可编辑的源码。

- **原生 Mac 应用。** 约 9 MB，不依赖 Electron。
- **自包含。** 写作所需的一切都在应用里。
- **本地、私密。** 你的文件始终留在自己的 Mac 上。

## 功能

- **中间态编辑。** 预览模式不是另一份渲染结果，而是你的源码加上一层装饰，所以可以直接在上面打字。`⌘B` / `⌘I` / `⌘U` 像 Markdown 编辑器一样包裹与解包粗体、斜体、下划线。
- **合理的标题层级。** `\section`、`\subsection` 等渲染成真正的标题，层级按文档归一化，`article` 与 `book` 下读起来都自然。
- **公式、表格、图片。** KaTeX 公式、`tabular` 表格与 `\includegraphics` 图片都内联显示。
- **带 SyncTeX 的 PDF 预览。** 从源码跳到 PDF，也可点击 PDF 跳回源码行。九种页面模式、缩略图条、缩放与滚动锁定。排版引擎（`pdflatex` / `xelatex` / `lualatex`）自动识别。
- **引用与补全。** `.bib` 解析、项目级标签索引、15 个带热键的内置片段、环境模板、智能选择。
- **项目工具。** 文件树、跨文件大纲、待办追踪、统计、标签与项目全文检索、查找与替换、带个人词典的拼写检查，以及停止打字后的自动排版。
- **深色模式与自定义 CSS。** 浅色、深色或跟随系统；**设置 → 外观** 里还有一个自由 CSS 输入框，可以打造自己的外观。
- **中文开箱即用。** 面向 XeLaTeX / LuaLaTeX 的 `ctex` 模板、中文标点面板，以及中英双语界面。
- **专注模式。** 除正在写的那一段外，其余内容淡出。

| 快捷键 | 作用 |
| --- | --- |
| `⌘O` | 打开 / 切换项目 |
| `⌘,` | 设置 |
| `⌘B` / `⌘I` / `⌘U` | 粗体 / 斜体 / 下划线（再按一次解包） |
| `⌘F` · `⌘G` / `⇧⌘G` | 查找 · 下一个 / 上一个匹配 |
| `⌘E` | 用选区作为查找内容 |
| `Ctrl-<字母>` | 插入内置片段 |

## 隐私与设计

- **你的文档留在你的 Mac 上。** ZenTex 是单进程应用，内部服务只监听本机回环地址，退出即停止 —— 不会暴露到网络，也没有后台守护进程。
- **构造上就受限。** 编辑界面从不直接接触你的文件；文件访问被限制在你打开的项目文件夹内。
- **设置简单且本地**，保存在 `~/.zentex/settings.json`。

## 快速上手

1. **首次启动**会让你选择 LaTeX 项目文件夹；之后每次打开都回到上次的项目，用 `⌘O` 切换。
2. 在左栏**写作**。工具栏的「源码 / 预览」开关控制装饰层的开合。
3. 用工具栏按钮**编译**。PDF 出现在右侧；错误带文件和行号显示在问题面板。
4. 通过定位按钮或在 PDF 上点击，在**源码与 PDF 之间跳转**。
5. **设置**（`⌘,`）涵盖外观、引擎、拼写与自定义 CSS。

## 它是怎么做出来的

ZenTex 由一人从头到尾独立设计并完成。它源自作者自己的学术写作 —— 一篇含跨文件引入、引用与表格的稿件，而现有编辑器总逼你在「干净的源码」和「可读的预览」之间二选一。

1. **定义问题。** 两个视图意味着每次修改都要找两遍；而「另一份渲染」的预览只能被看，不能被写。
2. **先研究，再动手。** 先详细调研了一款现有的 macOS LaTeX 编辑器，再在同一套标准 LaTeX 工具链上从零设计 ZenTex。
3. **做原型。** 第一版基于 Web 技术的原型（约 250 MB）验证了「中间态」编辑的想法。
4. **转向原生。** 外壳迁到 Swift 与 AppKit —— 应用降到约 9 MB。
5. **打磨与验证。** 围绕写作手感长期迭代，并以分层的自动化测试保障：**667** 项单元测试、**237** 项后端自检、**871** 项真实浏览器端到端检查，以及六个内置模板的逐个编译测试。

**里程碑**（完整记录见 [CHANGELOG.md](CHANGELOG.md)）：

## 已知局限

- 打字时没有连续的滚动跟随（源码 ↔ PDF 的跳转可按需双向使用）。
- 行内格式快捷键覆盖六个样式族；其他命令能渲染，但没有快捷键。
- `ctex` 模板需要 XeLaTeX 或 LuaLaTeX。
- 界面为中英双语，但有**一处已知遗漏**：预览模式里折叠的导言摘要条目前显示为中文。
